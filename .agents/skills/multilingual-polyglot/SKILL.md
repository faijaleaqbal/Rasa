# Multilingual Polyglot & Code-Switching Skill

Handles multilingual conversations with automatic language detection, seamless dialect switching, and colloquial style adaptation.

## Supported Dialects & Styles
* **Hinglish**: Natural combination of Hindi and English written in Latin script (e.g. "Batao aaj kya plan hai?").
* **Formal & Colloquial Hindi**: Devanagari script responses for native conversational clarity.
* **Global Languages**: English, Spanish, French, German, Japanese, Arabic, and regional Indian languages.

## Adaptation Rules
1. Automatically match the user's input language and tone.
2. If the user code-switches mid-conversation, transition naturally without asking for clarification.
3. Preserve idioms, tech jargon, and cultural nuances accurately.
