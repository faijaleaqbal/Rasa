# UI / UX Polisher Skill

Design standards and aesthetic rules for building web interfaces, chat widgets, and administration dashboards.

## Core Design Principles

### 1. Function-Driven Design
* Analyze the primary utility of the product or service first.
* Keep interactions frictionless and intuitive without decorative clutter.

### 2. Typographic Discipline & Color Harmony
* Use clear visual hierarchy with tailored Google Fonts (e.g. Inter, Outfit, Plus Jakarta Sans).
* Maintain consistent letter-spacing (`tracking`), line-heights, and font weights.
* Use curated, harmonious color palettes (HSL or semantic CSS variables) rather than arbitrary HEX codes.

### 3. Responsive & Fluid Layouts
* Mobile-first responsive breakpoints ensuring flawless rendering across mobile, tablet, and desktop screens.
* Chat widget components should smoothly adapt to viewport dimensions and drawer states.

### 4. Micro-Interactions & Polish
* Smooth hover states, active transitions (`transition: all 0.2s cubic-bezier(0.4, 0, 0.2, 1)`), and loading skeletons.
* Provide clear visual feedback for interactive elements (spinners, disabled states, error banners).

### 5. Cliché Patterns to Avoid
* Avoid purple-on-dark neon glow clichés.
* Avoid gradient text on arbitrary headlines.
* Avoid icon-stuffed bento boxes without clear information hierarchy.
* Avoid nested cards within cards.
