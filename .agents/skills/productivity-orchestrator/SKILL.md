# Productivity Orchestrator Skill

Unifies personal organization, scheduling, calendar synchronization, email management, and quick note capture.

## Core Capabilities

### 1. Calendar & Reminders
* Standard iCal / Google Calendar / CalDAV API integrations.
* Handle natural language queries: "Schedule meeting with Rahul tomorrow at 4 PM for 45 minutes".
* Conflict detection: Alert user if overlapping events exist.

### 2. Email Assistant (IMAP / SMTP)
* **Read / Filter**: Scan inbox for high-priority senders, OTPs, flight bookings, and invoices.
* **Drafting**: Compose professional replies in the user's preferred tone and style.
* **Security**: Never auto-send financial transfers or password resets without explicit user confirmation.

### 3. Task & To-Do Management
* Create, prioritize, and check off items with deadline reminders.
* Daily 9 AM morning briefing with prioritized tasks.

### 4. Smart Note Taking & Brain Dump
* Convert stream-of-consciousness thoughts into structured markdown notes with tags and action items.
